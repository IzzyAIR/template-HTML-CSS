# Статический сайт на HTML, CSS, Bootstrap и Swiper.js

Этот проект представляет собой статический сайт, созданный без сборщиков и runtime, используя HTML, CSS, Bootstrap и Swiper.js.

## 🚀 Технологии
- **HTML** – структура страниц
- **CSS** – стилизация и кастомизация
- **Bootstrap** – адаптивная верстка и UI-компоненты
- **Swiper.js** – слайдер для контента
